# Ver7.0 辞書確認と1,400語への追加候補

現行Supabaseを2026年9月8日に取得。登録513件、タイ語の完全一致で499種類、空白を除く表記で498種類です。

**1,400件まで887件。重複を除いた1,400語を目指すなら、少なくとも901〜902語の追加が必要です。** 句・文型も含むため、試験の語彙数とは厳密には一致しません。

L1/L2各100語を維持し、未割当からL3用200語を選抜。同じタイ語の重複、読み未登録、意味や欄の取り違えが疑われる項目は選抜から外しました。現行の意味・読みを勝手に修正していません。残る113件をすべて新語として数えることはできません。
